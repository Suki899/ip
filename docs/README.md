## Sorting tasks by date

Reorders your list so the earliest thing you have to deal with is at the top.

Deadlines are ordered by when they are due, and events by when they start.
Tasks with no date at all sit at the bottom, in the order you added them,
since they are never the answer to "what is coming up next?".

The new order sticks: it is what `list` shows from then on, and it is saved.

Example: `sort`

```
Sorted. Here are your tasks, earliest first:
1.[E][ ] project meeting (from: Oct 15 2019, 2:00PM to: Oct 15 2019, 4:00PM)
2.[D][ ] return book (by: Nov 1 2019)
3.[T][ ] read book
```
